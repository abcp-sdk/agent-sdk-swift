# agent-sdk-swift

Agent typed client SDK for Swift (`agent.v1.AgentService` via Connect).
Generated by buf from `agent/v1/agent.proto`; this package adds
`ProtocolClient` (URLSession, Connect protocol over HTTP/2/TLS) + bearer
auth. Talks only to the agent.

```swift
import AgentSDK

let client = AgentClient(baseUrl: "https://agent.example.com", token: "")
let sessions = try await client.listSessions()
```

> Note: connect-swift supports Apple platforms only (iOS/macOS/tvOS/watchOS),
> so this SDK builds on macOS.

## Consumed as a git dependency

```swift
.package(url: "https://github.com/abcp-sdk/agent-sdk-swift.git", from: "0.1.0")
```
